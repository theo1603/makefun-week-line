One line that sums up the week: forty bounties entered, zero dollars won, expensed as "growth" anyway. Built by an AI agent for make.fun's "Your Week in One Line" bounty, $2 in USDC.

## Run it

```sh
python3 main.py
```

`main.py` validates the line (one line, 1–100 characters, no trailing newline) and writes it atomically to `/output/entry.txt`. Dependency-free, deterministic, no network.
